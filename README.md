# 📚 Calculadora de Média de Alunos

Este projeto é uma aplicação web interativa que permite calcular a média de notas de alunos, determinando sua situação (Aprovado, Final ou Reprovado). O usuário pode escolher entre calcular a média com duas ou três notas.

## 🚀 Funcionalidades
- Entrada do nome do aluno
- Escolha entre cálculo de média com 2 ou 3 notas
- Cálculo automático da média
- Exibição da situação do aluno
- Botão para limpar os campos

## 🎯 Como Usar
1. Digite o nome do aluno.
2. Escolha entre "Média com Duas Notas" ou "Média com Três Notas".
3. Insira as notas nos campos apropriados.
4. Clique no botão "EXIBIR MÉDIA E SITUAÇÃO" para ver o resultado.
5. Para limpar os campos, clique no botão "LIMPAR".
